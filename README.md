# Vivify-Quest-Port-Collection
the easiest way to get an unofficial quest port for vivify
__________________________________________________________________
There are a lot of rumors about people getting vivify to work on a meta quest. In reality, these ports are unofficial and extremely buggy versions of an older version of the mod that are mostly made with AI. They have no optimization for standalone headsets whatsoever and can be stressful on the device's hardware.
__________________________________________________________________
I have tested two different versions of these unofficial ports:
One of them is the original unofficial quest port made by @Gay_Axolotl that I had to fork in able to build the QMOD file
The other one is a "fixed" version of that mod made by @rbatteries1-design
___________________________________________________________________
The links for both of those can be found here:

Original (QMOD file built): https://github.com/BigNate678/Vivify-Quest-Port
Fixed: https://github.com/rbatteries1-design/Vivify-Quest-Port
