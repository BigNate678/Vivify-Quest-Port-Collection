# Vivify-Quest-Port-Collection
There are a lot of rumors about people getting vivify to work on a meta quest. In reality, these ports are unofficial and extremely buggy versions of an older version of the mod that are mostly made with AI. They have no optimization for standalone headsets whatsoever and can be stressful on the device's hardware.
__________________________________________________________________
I have tested two different versions of these unofficial ports:
One of them is the original unofficial quest port made by @Gay_Axolotl that I had to fork in able to build the QMOD file
The other one is a "fixed" version of that mod made by @rbatteries1-design
___________________________________________________________________
The links for both of those can be found here:

Original (QMOD file built): https://github.com/BigNate678/Vivify-Quest-Port
Fixed: https://github.com/rbatteries1-design/Vivify-Quest-Port

___________________________________________________________________
Original port bugs and issues report:

Map 1: Breezer (backrooms version) - 
  Noticed Issues: When transitioning from the original Breezer map to the backrooms, there is a major freeze that lasts around 2 seconds.

Map 2: 3 BIG SHOTS FROM KITCHEN GUN - 
  Noticed Issues: Videos have significant delay, ultimately making the map confusing.

Map 3: Ego Death - 
  Noticed Issues: About 5 note arrows throughout the entire map are around 50% transparent.

Map 4: you - 
  Noticed Issues: Severe shader and blit malfunctions or absences, most of the map's notes having re-arranged/false arrows that point the player in the wrong direction, making the map unplayable and frustrating some notes changing colors while they fly towards you, confusing you and making the map even more unplayable, and most notes having the wrong color by default; basically the nail in the coffin for this map ever working with this port

Map 5: Light - 
Noticed issues: Severe and unplayable lag starting at the near end of the song and only getting worse as the song went on.

Noticed advantages of the original version: Heartbeat (a beat saber map) has working enviroments, and when a vivify map is selected the is significantly less delay between the time the map is selected and the difficulty's and play putton of that map is displayed.
________________________________________________________
I would say that the pros do not outweigh the cons for the original version and that you should most defadently stick to the fixed version. I will still leave the original version in case you guys want to try it out.
